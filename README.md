# Convert YouTube Video to M4A

This project converts YouTube videos to native, high-quality M4A (`.m4a`) audio files with AAC encoding.

## Converted Track

- **Title**: Kanye West - I Know I Know (I Thought About Killing You OG)
- **Source**: [https://youtu.be/jl1JfgbigP4](https://youtu.be/jl1JfgbigP4)
- **Format**: AAC in standard ISO M4A container (with faststart `moov` atom)
- **Duration**: 7:17
- **Bitrate**: 129 kbps
- **File**: [`Kanye West - I Know I Know (I Thought About Killing You OG).m4a`](./Kanye%20West%20-%20I%20Know%20I%20Know%20(I%20Thought%20About%20Killing%20You%20OG).m4a)

## Convert Another Video

To convert any other YouTube video to M4A:

```bash
./convert.sh "<YOUTUBE_URL>"
```
